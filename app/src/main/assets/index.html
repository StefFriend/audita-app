What Audita detects

Hearing protection

–

Daily limit: 80 dB for 8 hours (EU lower action value). Estimate from the headphone sensitivity set in Tune.

Channels

Following the source, phone calls come out mono in both ears and stereo room recordings stay stereo.

Noise reduction engine

Neural (RNNoise) gave the best results in our tests. Classic is a statistical spectral filter; Both keeps the stronger of the two at each frequency.

Processing blocks

Auto lets Audita decide from the recording. On forces a block even when it is not detected; Off removes it.

Options

Level-matched compare
The original is played at the same loudness as the processed sound, so the comparison is fair (louder always sounds better).
Room memory between files
Keeps the noise and reverb estimates when a new file starts: useful for many clips from the same place.
Shock guard
Holds sudden bangs (doors, knocks, a handled microphone) close to the level of the speech.
Telephone bass
Rebuilds the band below 300 Hz on phone calls, for a less thin voice. Part of the bandwidth extension.

Bandwidth extension envelope

How loud the rebuilt 3.4–7 kHz band is: estimated from the voice (learned on wideband speech) or a fixed −12 dB/octave slope.

Output ceiling

–dBFS

Maximum level the limiter lets through to the headphones. Lower is safer for the ears.

Headphone sensitivity

–dB SPL at full scale

Used only for the hearing dose. Leave 110 if unsure: it overestimates most headphones, which is the safe side.

Sample rate

96 kHz plays high-resolution files untouched (bypass), without the return to the computer. Audita restarts to change mode.

USB return to the computer

What the computer records from Audita: the processed voice before the volume, or exactly what you hear.

Processing load

Each block of audio is 10 ms long: the processing must stay well below that.

Switching firmware

Audita shares the board with other firmware. To change, power the board on while holding the knob pressed, turn the knob to choose, and press to start.
